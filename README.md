# NOIRSOLE — Static Sneaker Store

Sitio web estático inspirado en una tienda de sneakers/streetwear de estética editorial.

## Archivos

- `index.html` — página principal.
- `checkout.html` — pantalla de checkout/demo.
- `style.css` — diseño responsive.
- `script.js` — carrito básico usando localStorage.

## Ejecutar localmente

Abre `index.html` en tu navegador.

## Publicar con GitHub Pages

1. Crea un repositorio en GitHub, por ejemplo `noirsole-store`.
2. Sube `index.html`, `checkout.html`, `style.css`, `script.js` y este README.
3. En GitHub entra a **Settings → Pages**.
4. En **Build and deployment**, selecciona:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`
5. Guarda.
6. GitHub te dará una URL parecida a:
   `https://TU-USUARIO.github.io/noirsole-store/`

## Pago

El botón `PAY NOW — DEMO` solamente muestra un aviso. Para cobrar de verdad tendrás que conectar un proveedor como Stripe o Mercado Pago y nunca manejar datos de tarjetas directamente en este HTML.

## Imágenes

Las imágenes de demostración usan URLs externas de Unsplash. Puedes sustituirlas por imágenes propias dentro de una carpeta `images/`.
